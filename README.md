# حصين AI

مساعد عربي للأسئلة العامة والأمن السيبراني مع استوديو لتوليد الصور. يمكن التجربة كزائر، أو إنشاء حساب باسم مستخدم وكلمة مرور لحفظ المحادثات والصور في PostgreSQL. لا يُطلب بريد إلكتروني أو رقم هاتف.

## التشغيل

تأكد من وجود `DATABASE_URL`، ثم طبّق الجداول باستخدام `npx drizzle-kit push` وشغّل التطبيق. كلمات المرور تُخزّن بصيغة مشتقة باستخدام scrypt، والجلسة في ملف ارتباط HttpOnly. لا توجد آلية استعادة لكلمة المرور عبر البريد أو الهاتف، لذا يجب الاحتفاظ بها في مكان آمن.

## مزودات الذكاء الاصطناعي

يستخدم الموقع افتراضياً خدمات OVHcloud وPollinations المجانية، مع مزود صور احتياطي عند تعذر الأول. يمكن لمشغّل الموقع، اختيارياً، إعداد متغيرات البيئة `OPENAI_API_KEY` أو `POLLINATIONS_API_KEY` أو `OVHCLOUD_API_KEY` على الخادم؛ لا تظهر المفاتيح للمتصفح. يمكن تخصيص النماذج باستخدام `OPENAI_CHAT_MODEL` و`OPENAI_IMAGE_MODEL` و`POLLINATIONS_CHAT_MODEL` و`POLLINATIONS_IMAGE_MODEL`.

تُرسل الرسائل وأوصاف الصور إلى مزودي الذكاء الاصطناعي الخارجيين. تخضع الخدمة المجانية لحدود وتوافر المزود، ولا يمكن ضمان استخدام غير محدود أو عمل دائم. يُنصح بعدم إرسال معلومات حساسة. محدّد محاولات الدخول الحالي محلي لكل عملية تشغيل؛ في الإنتاج متعدد الخوادم يُنصح باستخدام مخزن مشترك لمحدد المحاولات، وتفعيل HTTPS والنسخ الاحتياطية.
